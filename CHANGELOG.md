## [0.1.0] - 2025-02-07

### Added
- Initial release of nls (nats-ls)
- Terminal UI for NATS message inspection
- Real-time subject monitoring
- Hierarchical subject display with condensing
- Subject filtering capabilities
- Message inspection with full payload viewing
- Multiple view modes (browse, inspect, log)
- Configurable NATS connection settings
- Configuration file support at `~/.nats-ls/config.yaml`
- Multi-platform builds (Linux, macOS for amd64 and arm64)
- Command-line flags for server connection override
- Version information command
